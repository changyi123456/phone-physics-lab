# Phylab 設計系統與入口頁規範

品牌由使用者確定為 **Phylab**（Physics + Laboratory）。定位：手機感測、電腦實驗的課堂工具。字標使用原生 Georgia/Times serif 粗體；繁中 UI 使用 PingFang TC/system-ui，數值與計時使用等寬字體。保留原 repo 與網址，避免既有手機連結失效。

## 視覺基準與結構

以本次 imagegen 的入口、目錄、實驗台與手機概念作基準；程式原生呈現文字、按鈕、QR Code 與圖表。生成圖只用於入口的手機／單擺概念插圖，不能代替可操作介面。

- 入口：安靜的字標／導覽／偏好列 → 開放式雙欄 hero → 分類與搜尋的雙欄實驗清單 → 三步使用方式 → 簡潔頁尾。預設精選 8 項，可展開全部 22 項；分類與搜尋查完整目錄。
- 實驗台：224px 深石墨色側欄，分類與搜尋；主區指引與大圖表；272px 右側配對與控制。中小螢幕將連線控制排到數據之前，讓使用者先完成必要動作。
- 手機：只顯示配對／授權／擺放／歸零／狀態；掃碼直接進感測頁，不經入口。
- 狀態：未連線不放假曲線；示範明示非實測；暫停、繼續、結束與手動 Excel 流程保留。量測中禁止返回；未匯出資料離開前確認。

## 文案與图示清單

入口首屏只允許 Phylab、手機感測・電腦實驗、實驗目錄、使用方式、主題／語言、「把物理現象，變成看得見的數據。」、既定說明、進入實驗室、試用示範、不用安裝 App／每組獨立連線／完成後下載 Excel。英文等義翻譯允許。無額外 eyebrow、假數據、口碑或帳號功能。

Hero 插圖：手機＋單擺＋概念波形；圖內沒有假測量數字。圖說註記為概念示意。字標為文字而非圖檔，確保語意與清晰度。

導覽圖示：Search 搜尋、ArrowRight 進入、ChevronDown 展開、Home 返回、Sun/Moon 主題、Globe 語言。實驗圖示採 1.7px 同系統線條：跑動加速度、旋轉角速度、傾角 Triangle、單擺細線與圓形、彈簧 zigzag、Orbit 向心、AudioLines 頻譜、ChartNoAxesColumn 頻率歷史、Camera/Palette 影像、MapPin 定位、Magnet 磁場、Sun 照度、SlidersHorizontal 自訂。操作為 Play/Pause/Square、ScanLine、Crosshair 校準、Download、Copy、RefreshCw、ExternalLink；保持意義與一致線寬。

## 功能性差異（刻意保留）

1. 概念中的手機畫面改為無量測數字的概念波形，避免誤認真實讀值；實際權限依瀏覽器。
2. 暗色與英文、錯誤／來源能力限制，依既有功能完整延伸。
3. QR 來自真實邀請；示範模式不顯示假 QR，改為示範說明與切回手機動作。
4. 操作指引可折疊，保留初次展開；短筆電縮小 QR，計時與控制始終易找。
5. 既有分析、多輪比較、教師 JSON 功能仍可在下方使用；不僅實作概念圖中可見的示意內容。

## 擴充規範

新增實驗使用 registry 的雙語 name/description/position/physics、catalog 的分類、同系列圖示與 sourceFor 的感測來源，不另造卡片系統。入口與側欄共用分類。支援狀態必須誠實，例如 Safari 不提供磁場／照度不能被呈現為可用。未經確認不加入外接器材、帳號或雲端保存。新動作必須符合量測狀態，離開與匯出規則一致。
