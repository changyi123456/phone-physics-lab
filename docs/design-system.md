# UI 設計系統

以生成的完整桌機與手機概念圖作視覺基準，使用者追加亮暗及中英切換為允許的改動。全介面為原生 HTML/React/canvas，不使用整張圖片作按鈕或圖表。

桌機：固定深藍 220–240px 實驗側欄、主工作區、280px 連線與控制欄。1366px 以上左右欄；較窄裝置連線欄改下方。手機感測器：單欄、清楚狀態、三步指引、主要授權與相對歸零動作。

亮色：canvas #ffffff；app #f5f7fb；text #172b4d；muted #62748f；border #dfe7f2；accent #2563eb。暗色：app #0b1220；surface #111d30；text #e6edf8；muted #96a8c3；border #26374f；accent #4e86ff。

中文字體 system-ui/PingFang TC/Noto Sans TC；正文14px、操作與指引15–16px、主標題28–32px；字距自然。圓角10px、間距8/12/16/24px。避免裝飾型漸層、行銷區塊、無意義數字。按鈕與分頁有 focus-visible。資料線 xyz 藍、青綠、橙；合量淺灰／紫。

側欄圖示採同一 lucide 系列線條，語意依序 Activity、RotateCw、Triangle、Cable、Waves、Orbit。動作 Play、Download、QrCode、Sun/Moon。控制字體與 chart 軸字體跟主題一致。

允許文字：產品名稱、六項實驗、操作指引、即時數據／分析結果、含重力／線性加速度、手機連線、校準、開始量測、結束並匯出 Excel、單位、取樣率、已經過時間、資料品質；對應英文與繁中。其他內容僅為已確認流程所需錯誤、權限與模型說明。

動態狀態（配對、示範、記錄中、停止確認、匯出）與參數／原理 details 依同系統延伸。生成圖中 QR 只是視覺位置，實作必須真實生成邀請 URL 的 QR。桌機初始未連線不顯示合成曲線；示範需明顯標籤。
