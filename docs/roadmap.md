# 擴充進度 v0.2

本次依要求完成純網頁可實作的量測與分析。依最新範圍保留 22 個入口：6 個原模組、14 個新增模組與 2 個依 API 條件啟用的內建感測入口。iPhone 不一定提供磁場與照度 API。

## 已暫緩項目

依使用者最新指示，移除外接 Bluetooth／USB 感測器、氣壓、接近距離、深度／ToF 及需要狹縫／光柵的光譜功能；本版不建置這部分。

## 有條件可用

- 磁場／照度需瀏覽器暴露 Generic Sensor API 且授權成功；iPhone Safari 通常不提供。

## 尚需真實課堂驗收與營運決策

- [ ] iPhone Safari、Android Chrome 實體動作／麥克風／相機／GPS，記錄系統版本、實際 rate 與偏差。
- [ ] 校園 Wi-Fi↔行動網路、受限網路 TURN 路徑、30 組×10 分鐘真實課堂驗收；程式模擬另列。
- [ ] 已知音源、相機曝光影響、GPS 戶外基準、聲音誤觸發／漏觸發。
- [ ] 公共信令／TURN 生產穩定性與可替換配置；現在沿用公開 PeerJS 網路。
- [ ] 更長聲學量測與更大匯出資料量，須先改傳輸／記憶體預算。
- [ ] 兩手機同步／全班聯動是不同產品範圍；目前依原要求各組獨立，未加入。
