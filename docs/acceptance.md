## 驗證環境與方法

本機網址 http://localhost:5178。先以 Codex 內建瀏覽器確認完整可見畫面，操作校準、開始、結束、語言及主題，查看 AX 與 console。Browser plugin 未列於本次技能；IAB 的 Blob 下載事件兩次逾時，但 UI 已完成 Excel 產生。依前端技能改用已安裝的獨立 Playwright Chromium 驗證下載檔案、兩端 WebRTC 及截圖，未安裝新的瀏覽器。

測試感測訊號只在隔離 QA 頁面注入，正式網站不提供隱藏注入 API。測試檔案名稱包含 SYNTHETIC-FIXTURE；檔內手機來源欄位只表示傳輸路徑，不能視為實體感測證據。

桌機 1536×1024 與筆電 1280×720；手機 390×844，長頁允許垂直捲動。桌機六模組逐一切換；繁中／英文按鈕、指引與圖表一起切換；Excel 另回讀確認語言及 numeric cell。
